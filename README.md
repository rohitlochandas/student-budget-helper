# Student Budget Helper 💜

A student-friendly personal finance tracker to manage monthly budgets, track expenses, and achieve savings goals.

## 🌐 Live Demo
https://student-budget-helper.vercel.app/

## 💻 GitHub Repository
https://github.com/rohitlochandas/student-budget-helper

## Features
- Monthly budget management
- Daily expense tracking
- Expense category charts
- Budget warning alerts
- Savings goal tracker
- Daily spending suggestions
- Affordability calculator

## Built With
- HTML
- CSS
- JavaScript

## Purpose
To help students develop smarter spending habits and better financial management skills.
